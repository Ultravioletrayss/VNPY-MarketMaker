**CtaBacktester - CTA回测研究模块 程序员速查表**

### 1. 模块加载

```python
from vnpy_ctabacktester import CtaBacktesterApp
main_engine.add_app(CtaBacktesterApp)   # 创建 main_engine 后添加
```

---

### 2. 主要功能流程（UI 操作速查）

| 操作 | 触发方式 | 关键配置参数 | 注意事项 |
|------|----------|-------------|---------|
| **下载数据** | 【下载数据】按钮 | 本地代码 (`vt_symbol`)、K线周期 (`1m/1h/d/w/tick`)、开始日期、结束日期 | 数据保存至本地数据库，后续回测可复用 |
| **执行回测** | 【开始回测】按钮 | 策略名称、本地代码、数据范围、滑点、手续费、合约乘数、价格跳动、回测资金 | 需先确保历史数据充足 |
| **参数优化** | 【参数优化】按钮 | 优化目标函数、参数范围（开始/结束/步进）、优化算法 | 支持穷举 + 多进程、遗传算法 |
| **代码编辑** | 【代码编辑】按钮 | 选择策略 | 调用系统 VS Code |
| **策略重载** | 【策略重载】按钮 | - | 修改代码后必须执行，使内存生效 |

### 3. 回测核心配置参数

| 参数类别 | 参数名 | 类型/格式 | 说明 |
|---------|--------|----------|------|
| **策略** | 策略名称 | str (下拉选择) | strategies 目录下的策略类 |
| **标的** | vt_symbol | str | 如 `IF888.CFFEX`、`rb888.SHFE` |
| **数据** | 开始/结束日期 | `yyyy/mm/dd` | - |
| **数据频率** | interval | `1m`, `1h`, `d`, `w`, `tick` | - |
| **交易成本** | 滑点 (slippage) | float | 点数 |
| **交易成本** | 百分比手续费 | float (如 0.0003) | 不要带 `%` |
| **合约属性** | 合约乘数 (size) | int/float | - |
| **合约属性** | 价格跳动 (pricetick) | float | - |
| **账户** | 回测资金 (capital) | float | 起始资金 |
| **模式** | 合约模式 | 正向 | 目前主要支持正向 |

---

### 4. 优化参数配置

| 项目 | 配置方式 | 示例 |
|------|---------|------|
| **目标函数** | 下拉选择 | 总收益率、夏普比率、收益回撤比 等 |
| **待优化参数** | 开始 / 结束 / 步进 | 10 / 20 / 2 → 10,12,14,16,18,20 |
| **固定参数** | 开始 = 结束 | 开始=15, 结束=15 |
| **优化算法** | 多进程优化（穷举） / 遗传算法优化 | 多进程利用 CPU 核心数 |

### 7. 程序员常用代码片段（脚本化调用）

虽然 CtaBacktester 主要通过 UI 使用，但底层引擎可脚本调用（参考官方示例）：

```python
from vnpy_ctabacktester import BacktesterEngine
from datetime import datetime

engine = BacktesterEngine()

# 添加策略
engine.add_strategy(YourStrategyClass, "strategy_name", vt_symbol, setting_dict)

# 设置参数
engine.set_parameters(
    vt_symbol=vt_symbol,
    interval="1m",
    start=datetime(2020, 1, 1),
    end=datetime(2023, 12, 31),
    rate=0.0003,      # 手续费
    slippage=0.0,
    size=contract_size,
    pricetick=pricetick,
    capital=1000000
)

# 加载数据并运行
engine.load_data()
engine.run_backtesting()
result = engine.calculate_result()   # 统计结果
engine.calculate_statistics()        # 输出统计指标
```

**注意**：实际脚本化回测常直接使用 `vnpy_ctastrategy` 中的 `BacktestingEngine`（CtaBacktester 是其图形包装）。
